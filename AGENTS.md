# AGENTS.md

**2code for Herdr**: layout `layouts/2code.json`, mod `mods/2code/`, themes
`themes/`. How it works: [RECIPE.md](RECIPE.md). The old
Tauri app is on branch `legacy-tauri-app`; don't bring its code back.

## Herdr

- UI = files in `~/.config/herdr-app`: JSON layouts, JS mods drawing native
  GPUI. No HTML, CSS, DOM, `setTimeout`, `Intl`, Node APIs.
- API truth: installed `~/.config/herdr-app/AGENTS.md`, `herdr.d.ts`,
  `gpui-kit.d.ts`. Read before using something new.
- Prefer Herdr features and shipped mods (`files`, `changes`, `worktree`,
  `menu`, ...). They're read-only: reference, or `mod.clone`.

## Mod

- One mod folder (Herdr rejects imports outside it). Block picks a part:
  `{"mod": "2code", "props": {"part": "<name>"}}`; `parts/`, registered in
  `main.js`.
- `lib/`: `i18n`, `git`, `config` (2code.json), `projects`, `changes` (git
  status / diff / commit / history), `editor` (files as tabs), `fileops`,
  `fileIcons` (generated by `scripts/build-file-icons.mjs`; don't edit),
  `terminal`, `os`, `ui` (shared popup / dialog helpers).
- `keys.json` commands `2code.<name>` reach every part with `command()`;
  each ignores names it doesn't know.
- Strings: `t()` with `en` + `zh` in `lib/i18n.js`. Locale only from
  `LC_ALL` / `LC_MESSAGES` / `LANG` via `exec`, else English; no switcher.
  Parts read `shared("2code.locale")` in `render`.
- `parts/files.js`, `parts/changes.js` derive from Herdr's shipped mods
  (Apache-2.0): keep `NOTICE` and `LICENSE-Herdr.txt`.
- Never keep a `cx`. Async `cx.spawn`, wait `cx.sleep(ms)`, poll gently
  `cx.timer.every`.
- Git reads use `READ` (`--no-optional-locks -c core.fsmonitor=false`,
  `lib/git.js`): no folder-watch triggers.
- State: shared `2code.projects`, `.editors`, `.dirty`, `.editorRequest`,
  `.review`, `.locale`, `.filesRefresh`; `localStorage` for UI. Worktrees from
  git, config from `2code.json`, open files from Herdr tabs.
- Runtime gotchas: read RECIPE.md "Watch out" before UI work.

## Test

```sh
./scripts/install.sh                       # copy into ~/.config/herdr-app + herdr-app check
herdr-app do layout.switch --name 2code
herdr-app status                           # errors from files and mods
herdr-app shot /tmp/2code.png              # what the window shows
```

Done = passing `herdr-app check` + a look in the running app. Copy, never
symlink (no SVGs or hot-reload through symlinks). Update `RECIPE.md` with
behavior changes.
